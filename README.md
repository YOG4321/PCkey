# PCkey

PCkey 是一款面向 Windows 的开源用户态键盘改键工具，支持 Layer、Tap-Hold、
Tap Dance、Combo、按键宏、Key Override、媒体键、鼠标键和常用系统快捷操作。

当前维护版本：**0.5.0-dev**

## 当前版本

完整源码位于 [`0.5/`](./0.5/)，包括构建配置、测试、设计文档、许可证和当前版本
README。进入该目录后可按其中说明使用 CMake 构建 `PCkeyCore.exe`、
`PCkeyEditor.exe`，并运行自动化测试。

## 快速开始

请先阅读 [`0.5/README.md`](./0.5/README.md) 中的构建和使用说明。通常流程是：

1. 构建并启动 `PCkeyCore.exe`；
2. 打开 `PCkeyEditor.exe` 创建或编辑配置；
3. 点击“保存并应用”；
4. 使用“按键测试”确认物理输入和配置输出。
